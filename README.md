# Različne aktivnosti

## Opis naloge
Aplikacija je narejena v Android Studiu z uporabo programskega jezika **Java**. Namen naloge je spoznati delo z več aktivnostmi (Activities) in prenos podatkov med njimi.

## Funkcionalnosti

Aplikacija vsebuje tri aktivnosti:

- **MainActivity** – prikazuje števec in omogoča njegovo povečevanje. Omogoča tudi prehod na drugi dve aktivnosti.
- **HelloActivity** – prikaže pozdravno sporočilo in vrednost števca, ki jo prejme iz glavne aktivnosti.
- **ThirdActivity** – prikaže tretjo aktivnost in prejeto vrednost števca. Omogoča navigacijo med aktivnostmi.

## Prenos podatkov

Za prenos vrednosti števca med aktivnostmi uporabljamo:
- `Intent.putExtra()` – za pošiljanje podatka.
- `getIntent().getIntExtra()` – za sprejem podatka.

## Uporabljene tehnologije

- Android Studio
- Java
- XML za oblikovanje uporabniškega vmesnika
- Android Activities
- Intents za prehajanje med aktivnostmi
